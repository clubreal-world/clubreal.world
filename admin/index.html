sign in

Enter your GitHub access token. It acts as the password: only someone with a valid token can publish, and it is only ever sent to GitHub.

how do I get a token?
  1. Sign in to GitHub, then open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token. Pick an expiration date.
  3. Under Repository access, choose Only select repositories and pick clubreal-world/clubreal.world.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it, and paste it above.
